# CrashDash Marketing

Public marketing website for CrashDash.

https://www.crashdash.ai

This repository contains only the files and assets required to render the
public CrashDash marketing website.

Private application logic, research pipelines, automation, operational
documentation and credentials are maintained outside this repository.

## Public repository rule

Only commit:

- public HTML
- public CSS
- browser-side JavaScript
- public images
- public cinematic/media assets
- crawler/domain configuration
- deliberately public marketing material

Do not commit:

- operational documentation
- Apps Script source
- private automation
- runbooks
- internal architecture
- pipeline/scanner logic
- internal hostnames or filesystem paths
- secrets or credentials
- customer/form-response data
- internal prompts/design packs

Everything in this repository must be assumed readable by anyone on the
internet.

Do not include detailed internal setup instructions in the README.
